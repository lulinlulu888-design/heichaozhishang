## 目录约定

- `tools/`：可复现的提取、解析和分析工具。
- `analysis/`：本地证据、清单、提取物与阶段报告（默认不提交版本库）。
- `packages/game-protocol/`：已恢复的原协议数据层及测试；新客户端接口不必沿用旧服协议。
- `packages/battle-core/`：可供 Node/Cocos 集成的已恢复标量公式，不等同于完整战斗状态机。
- `packages/battle-presentation/`：新客户端的快照与动作播放状态投影，无引擎依赖。
- `packages/battle-session/`：显式重建规则的回合状态机，可保存、恢复和继续战斗。
- `clients/cocos-poc/`：Cocos 工具链、角色/卡牌图鉴、本地档案与首战界面原型；图形战斗运行待验收。
- `server/`：新客户端本地 API、目录数据投影与 SQLite 档案存储。
- `runtime/`：本地运行存档与日志，默认不提交版本库。

## Node.js 验证

```powershell
pnpm install --ignore-scripts --frozen-lockfile
pnpm test
```

启动新客户端使用的本地服务：

```powershell
pnpm server
```

默认监听 `127.0.0.1:7457`，档案保存在 `runtime/server/hczs.sqlite`，战斗存档为对应 `.battles` 文件。教程依赖已恢复的首战数据；仅图鉴模式可用 `node server/src/index.js --no-tutorial`。

命令行运行首战：

```powershell
pnpm tutorial
```

输入牌序号出牌、`e`结束回合、`q`退出。每一步自动保存，再次运行恢复未完成战斗。此入口使用独立服务和存档。Cocos图鉴中的“进入序章首战”已接入同一API，图形实际运行尚未验收；不代表原APK登录或完整游戏已恢复。
